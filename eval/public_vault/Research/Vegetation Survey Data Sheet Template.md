# Vegetation Survey Data Sheet Template

## Field Record Layout

| Column | Description | Units |
|--------|-------------|-------|
| Plot_ID | Unique plot identifier | alphanumeric |
| Date | Survey date | YYYY-MM-DD |
| Observer | Field recorder name | text |
| Species_Code | Four-letter USDA code | code |
| Height | Vegetation height at crown | cm |
| Canopy_Cover | Areal coverage percentage | % |
| Vigor | Growth rating 1–5 | ordinal |
| Notes | Condition or damage | text |

## Data Quality Requirements

- All entries written in black ink to ensure archival durability
- Height measurements taken with a metric pole to nearest 5 cm
- Canopy cover estimated using ocular methods, recorded in 10% increments
- Vigor ratings follow USDA standards: 1=dead, 2=poor, 3=fair, 4=good, 5=excellent
- Survey sheets are photographed at the end of each day for backup
