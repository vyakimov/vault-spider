# Equipment Loan Log

## Tracking Portable Field Equipment

Small, portable equipment items (GPS units, spare battery packs, handheld radios, tablets) are shared across the field team. This log tracks which items are checked out to which visit to ensure accountability and prevent loss.

## Log Columns

| Date | Team Member | Equipment Item | Qty | Purpose / Site | Expected Return | Returned Date | Notes |
|------|------------|---|-----|------|--------|---|---|
|      |            |   |     |      |        |   |   |

## Equipment Categories

- **GPS Units** (3 available): Garmin eTrex, calibrated annually
- **Battery Packs** (6 available): 20,000 mAh USB-C, used for tablet and radio charging
- **Handheld Radios** (4 available): See Two-way Radio Etiquette for channel assignments
- **Field Tablets** (2 available): iPad Mini, running Fieldwire app for note-taking
- **Headlamps** (6 available): Petzl Tikka, spare batteries included in field kits

## Return Procedure

Equipment must be returned within 24 hours of the completed fieldwork visit, unless an extended checkout is approved by the station coordinator. Upon return:

- Inspect the item for damage and record any issues in the Notes column
- Recharge batteries to full capacity before returning to storage
- Clean muddy or wet equipment and allow it to dry
- Store all items in the designated equipment cabinet

Equipment not returned within 2 weeks is considered overdue; the station coordinator will follow up with the responsible team member.
