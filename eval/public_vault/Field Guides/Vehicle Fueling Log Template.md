# Vehicle Fueling Log Template

## Column Headings

Record each field-vehicle fueling event on a new line with the following columns (monthly sheets stored in the equipment cabinet):

| Date | Odometer (km) | Fuel Amount (L) | Station Visited | Driver Initials | Cost ($) | Pump Location |
|------|---------------|-----------------|-----------------|-----------------|----------|----------------|
|      |               |                 |                 |                 |          |                |

## Completion Instructions

**Date**: Calendar date in YYYY-MM-DD format. Include time if multiple fill-ups occur on the same day.

**Odometer**: Record the vehicle's odometer reading immediately after fueling. This tracks average fuel consumption across field visits.

**Fuel Amount**: Actual litres pumped (shown on pump display). Round to 0.1 L.

**Station Visited**: Either "North Ridge", "South Meadow", or "Transit" if fuel was purchased on the road between sites.

**Driver Initials**: First initial and last initial of the person operating the vehicle on that visit.

**Cost**: Total cost in dollars, if a receipt is available.

**Pump Location**: Name of the fuel station or which vehicle is using fuel from the bulk tank at the office.

## Monthly Summary

At the end of each month, total the fuel column and calculate average litres per visit. Submit the completed sheet to the station coordinator by the 5th of the following month.
