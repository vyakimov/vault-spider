# Atlas Sensor Hub Rollout - Phase 1

## Deployment Timeline

Phase 1 spans six months, deploying to the North and West regions with four stations per region. Each region receives sequential deployment: site surveys in month one, equipment staging in month two, installation and commissioning in months three through five, and stabilization monitoring in month six.

## Site Prioritization

Sites selected based on data collection criticality and infrastructure maturity. North region stations cluster near existing monitoring posts with electrical access already established. West region requires new building partnerships but offers superior network coverage for LoRaWAN backhaul.

## Success Criteria

All eight stations achieve 95% data availability in their first operational month. Field technician response time to station issues averages under eight hours. No unplanned outages exceed four hours.
