# Atlas Sensor Hub Decommission Plan - Old Loggers

## Legacy System Inventory

Seventeen manual data logger stations currently operated by field staff with monthly on-site memory card retrieval. Data transferred to regional archives after manual QA verification. This process requires 60-80 staff hours monthly across all regions.

## Migration and Parallel Operation

Phase 1 Atlas stations deployed alongside legacy loggers at four existing locations to establish data continuity. Six months of parallel operation planned to confirm Atlas readings align with established baselines before logger decommissioning. Any discrepancies trigger investigation and potential sensor recalibration.

## Decommissioning Timeline

After Phase 1 stabilization, legacy loggers at North and West regions retired. Data archives migrated to centralized storage with full indexing. Field staff reallocated to support expanded Atlas network operations and maintenance.

## Hardware Disposal and Records

All logger hardware catalogued and returned to equipment depot. Batteries properly recycled through e-waste vendor. Retention of all historical data in perpetuity; archive access requires written request to regional coordinators with data classification review.
