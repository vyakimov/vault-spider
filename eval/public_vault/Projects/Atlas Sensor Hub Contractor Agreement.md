# Atlas Sensor Hub Contractor Agreement

## Statement of Work

Contract engages specialized embedded systems consultant to design and validate Cedar gateway firmware, including LoRaWAN protocol integration and SQLite queue implementation. Scope includes architecture review, code development, field testing, and documentation of operating parameters.

## Deliverables

- Cedar firmware v2.6 and v2.7 feature implementations
- Integration test suite for LoRaWAN message handling
- Field trial report covering 30 days of operational stability at deployment site
- Technical documentation for future maintenance and version control

## Budget and Timeline

Engagement runs from March through August 2024 with monthly milestone checkpoints. Budget reserved for equipment procurement (LoRaWAN test gateway, evaluation boards) and travel for on-site field trial validation at the environmental monitoring site.

## Acceptance Criteria

Firmware must maintain >99% message reception rate over 7-day continuous operation, support graceful queue draining during planned maintenance windows, and provide clear diagnostic output for troubleshooting network issues.
