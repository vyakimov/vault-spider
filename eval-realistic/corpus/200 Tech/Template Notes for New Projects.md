# Template Notes for New Projects

A rough template used when starting a new homelab project note to keep documentation consistent.

## Template Structure
Each new project note starts with a brief summary of the goal. Then I add sections for **Why** (the motivation), **What** (what I'm building), **How** (the technical approach), and **Results** (what actually happened). This structure works across different project types. As the project evolves, I add sections for **Lessons** and **Future Improvements** based on what I learn.

## Evolution in Practice
I don't rigidly stick to the template—some projects skip sections or add new ones as needed. Small hacks might only have Why and Results. Complex infrastructure projects get deeper How sections. The template is a starting point that prevents staring at a blank page and encourages capturing motivation and lessons learned. Over time, these notes become a project archive showing what worked, what didn't, and why certain decisions were made.
