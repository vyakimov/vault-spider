# Password Manager Migration

Moving from browser-saved passwords to a dedicated password manager after one browser update nearly lost them all.

## The Scare
Firefox was doing a major version bump and the migration warnings were vague. I realized I had 80+ accounts stored entirely in the browser, with no export. The thought of losing those or getting locked into Firefox escalated things. I spent a weekend pulling passwords from the browser's encrypted store, importing them into Bitwarden, and testing each account type. Never again.

## New Workflow
Every new password goes into the manager first. The browser gets a blank fill-in, and I paste from the manager. It's one extra step, but now I have a searchable vault that's not tied to a specific browser. I also filled in security questions, backup codes, and notes for each account. The process took longer than expected but it's genuinely easier to use now when I need to recover an account or switch machines.
