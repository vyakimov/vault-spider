# Weekend Project Backlog

A running list of homelab project ideas that seem promising in theory but mostly languish in the backlog, rarely getting built.

## Active Projects (Probably Won't Happen)
Build a dedicated jump server in the tailnet to reduce direct access to sensitive machines—would take about 20 hours to configure properly. Set up a metrics dashboard that aggregates drive health, network bandwidth, and power consumption—interesting but I'd spend more time on the dashboard than looking at it. Create a NAS mirror at a remote location for redundancy—requires trust and coordination that I haven't found with anyone yet.

## Wishlist Items
Automate the backup rotation with a cron script instead of manual quarterly swaps. Set up a Raspberry Pi cluster for distributed computing experiments. Build a home lab test environment that mirrors production before pushing changes to the live server. Most of these projects are fun to think about but lower priority than maintaining what already works. The backlog serves as a reference when I have a rare free weekend and the mood to tinker.
