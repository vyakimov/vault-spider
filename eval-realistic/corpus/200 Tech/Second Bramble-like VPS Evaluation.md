# Second Bramble-like VPS Evaluation

Comparing a second cheap VPS provider as a redundancy measure in case the current Bramble host experiences an outage.

## Current Bramble Setup
I run a lightweight VPS on a small provider for exit node duties and occasional build workloads. The provider has been stable for two years but they're a smaller operation. If they have downtime or sudden closure, I'd lose the exit node and any running containers. A second VPS from a different provider would let me fail over quickly.

## Evaluation Criteria
I'm looking for similar specs at comparable cost—1 vCPU, 2GB RAM, 50GB SSD. Checking uptime histories and support responsiveness. Avoiding mega-clouds like AWS since the whole point is decentralization and cost efficiency. Found a secondary provider with good reviews and a 9-month trial discount. Plan to keep it on standby with a mirrored configuration so I can flip traffic over if needed. Haven't pulled the trigger yet—the setup complexity isn't worth it unless downtime becomes a pattern.
