# Fernweh Packing List Templates

Reusable packing list templates by trip type (camping, city, beach).

## Templates
Each template is a markdown checklist with categories: clothing, documents, toiletries, electronics, activities. The camping template includes tent/sleeping bag/cook gear; the city template skips outdoor gear and emphasizes professional clothes; beach template adds sunscreen and swim gear.

## Customization
When I create a new trip, I start with a template and add/remove items based on the specific destination. I check items off as I pack, then save the final list as a new template variant if it was significantly different.
