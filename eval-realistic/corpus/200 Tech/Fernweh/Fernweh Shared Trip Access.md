# Fernweh Shared Trip Access

Read-only trip sharing with a travel companion without giving edit access.

## Sharing
I generate a unique token for each trip that grants read-only access. The token URL is shareable via email or messaging, and expires 30 days after the trip end date. Viewers can see the itinerary, budget, and packing list but can't modify anything.

## Use Case
I share this link with travel companions so they can check the itinerary and see what's already been packed. This prevents duplicate packing and keeps everyone aligned on timing. Since it's read-only, I'm not worried about accidental edits.
