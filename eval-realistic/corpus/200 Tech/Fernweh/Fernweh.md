# Fernweh

Hub note for Fernweh, a trip-planning notes app replacing a pile of shared documents.

## Problem Statement
I was managing trips using shared Google Docs for every traveler—messy, scattered, and no way to track what we've actually done vs. what we planned. Fernweh consolidates trips, itineraries, accommodations, and packing lists in one place.

## Features
Each trip has an itinerary (timeline of activities), a budget tracker, a packing list, and a document archive (confirmations, maps, etc.). Multiple people can view and edit the same trip. The app runs as a Vue.js frontend against a JSON API on Bramble.
