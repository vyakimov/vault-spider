# RSS Reader Setup

Self-hosting a small RSS reader instead of using a cloud service.

## What I Chose
I run Miniflux in a container on Blackbird. It's minimal, lightweight, and doesn't require any auth setup beyond a password. I subscribe to about 30 feeds: tech blogs, a few news outlets, project release feeds. It syncs across devices so I can read on the phone, laptop, or tablet without worrying about which one I read it on.

## Workflow
I scan headlines in the morning, mark read, and flag anything that deserves deeper engagement. Flagged articles go into a "to-read" folder in the vault. Most just get skimmed and deleted. The setup is stripped down by design—no recommendation algorithms, no infinite scroll, just a list of feeds. If a feed goes inactive (no posts in 3 months), I unsubscribe. It keeps the noise down and the signal clear.
