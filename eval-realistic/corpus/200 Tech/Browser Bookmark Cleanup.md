# Browser Bookmark Cleanup

A one-time pass merging years of browser bookmarks before Millwright existed.

## What Happened
I realized I had bookmarks from three browser migrations spanning 8 years. Some were duplicates, many were dead links. I exported everything into a massive HTML file, de-duped by checking which links still returned 200 status codes, and organized the survivors into a simple folder structure: Work, Reference, Blogs, Archive.

## Outcome
Went from 500+ bookmarks to about 180 that are actually useful. Most of what I used to bookmark (code snippets, tutorial links, documentation) now gets stored as notes or archived in the vault. Bookmarks are mostly for "I might need this today" links. Everything else is a search query away. The cleanup took a weekend and I've maintained it since—new bookmarks go through a mental filter: "Will I actually use this again in the next month?" If not, it doesn't get saved.
