`brew list --cask` shows installed casks; `brew install --cask firefox vlc utm` installs GUI apps. Update: `brew upgrade --cask`. Search: `brew search zoom`. Cleanup old versions: `brew cleanup --cask`. Prefer cask over DMGs for easier uninstall (`brew uninstall --cask firefox`) and updates.
