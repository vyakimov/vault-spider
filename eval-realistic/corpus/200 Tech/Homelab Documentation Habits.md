# Homelab Documentation Habits

A reflection on why this personal vault became the primary documentation system instead of maintaining a separate wiki or status page.

## Why Not a Separate Wiki
I experimented with a dedicated documentation site and a status dashboard, but they felt like extra burden. The wiki would fall behind because it required context switching and dedicated upkeep. A status page would fail when I didn't update it, rendering it useless. Having documentation scattered across docs, wikis, and my head was worse than not having it at all.

## Vault as Documentation
Keeping everything in this vault—project notes, configurations, lessons learned, decision logs—made it natural to maintain. The same system I use for personal notes now holds the homelab documentation. Search and backlinks make finding old decisions easy. Since I use the vault daily, the documentation stays fresh by accident. Adding a new note about a project or decision is frictionless compared to maintaining a separate system. The vault has become the canonical source of truth for my setup.
